# README
本项目为同济大学国豪书院23级计算机科学与技术精英班《数字逻辑》与《数字逻辑实验》（授课教师GYC）课程课件、平时作业与期末项目。项目仅供学习与交流，切勿全盘复制。

### 关于期末课程设计
本仓库的课程设计为键盘控制的俄罗斯方块游戏，外设为键盘（并非老师提供）与VGA显示屏。可参考其他学长学姐的课程设计并作调整修改。

### 关于复习备考
郭老师给分超好，题目大多来源于《数字逻辑习题解析与实验教程》（科学出版社）一书，只需把题目全部做完做会，再简单复习一下verilog语言足矣！
不过，考试选填分值相对较大，尤其是填空题会在整本书中挑原句挖空。因此除了做复习题，还要通读全书，搞定这两项拿U真的不难！
